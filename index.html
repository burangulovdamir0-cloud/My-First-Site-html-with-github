О проекте

Этот проект создан для демонстрации процесса работы с системой контроля версий Git и хостингом репозиториев GitHub.

На этой странице показан пример простого веб-сайта с использованием HTML и CSS.

Использованные Git команды

git init

Инициализация нового репозитория Git в текущей папке

git add .

Добавление всех измененных файлов в область подготовленных файлов

git commit -m "..."

Фиксация изменений с комментарием

git push

Отправка зафиксированных изменений в удаленный репозиторий

Процесс работы

  1. Создание HTML и CSS файлов
  2. Инициализация Git репозитория
  3. Добавление файлов и создание первого коммита
  4. Создание репозитория на GitHub
  5. Привязка локального репозитория к удаленному
  6. Отправка файлов на GitHub
  7. Внесение изменений и повторная отправка
